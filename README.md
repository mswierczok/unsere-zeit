# Unsere Zeit

Private Kalender-Web-App für zwei iPhones auf GitHub Pages. Die Website ist öffentlich erreichbar; echte Kalenderdaten werden vor der Veröffentlichung AES-GCM-verschlüsselt. Keine Zugangsdaten oder MYDUTY-Freigabelinks in dieses Repository eintragen.

Einrichtung: **Settings → Pages → Source → GitHub Actions**. Danach unter **Settings → Secrets and variables → Actions** die erforderlichen Secrets setzen und den Workflow manuell ausführen.

Für den ersten Besuch ist eine Demo mit Beispielterminen vorgesehen. Live-Daten benötigen die separate Synchronisierung.
